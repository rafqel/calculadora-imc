# BMI Calculator

A responsive web application for calculating Body Mass Index (BMI) and providing educational health information. Developed with HTML, CSS, and JavaScript.

## About

I developed this BMI calculator as part of my Extension Activity II. The application accepts user input (weight and height), calculates the Body Mass Index, and presents the corresponding classification based on World Health Organization (WHO) ranges. It was built with HTML, CSS, and JavaScript, with careful attention to responsive design and accessibility across devices.

The project also includes an educational section with general health tips and personalized recommendations according to the user’s result. This content is intended for awareness and educational purposes only and does not replace evaluation by a qualified healthcare professional.

## Features

- Input fields for weight (kg) and height (m)
- Instant BMI calculation
- Classification according to WHO reference ranges:
  - Underweight
  - Normal weight
  - Overweight
  - Obesity class I, II, and III
- Color-coded result (green for healthy range, red for attention)
- Educational section with general health tips:
  - Balanced diet
  - Physical activity
  - Hydration
  - Quality sleep
  - Mental health
  - Regular check-ups
- Personalized recommendation based on the calculated BMI
- Responsive layout for mobile and desktop
- Client-side only: no personal data is stored, transmitted, or shared

## Technologies

- **HTML5** – semantic structure
- **CSS3** – responsive layout, Flexbox and Grid
- **JavaScript (ES6)** – BMI calculation and DOM manipulation
- **Font Awesome** – icons
- **Google Fonts (Poppins)** – typography

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/rafqel/calculadora-imc.git
   ```

2. Open the `index.html` file in your browser, or run it with Live Server in VS Code.

3. Enter your weight (kg) and height (m), then click **Calculate**.

4. View your BMI, classification, and personalized health recommendation.


## BMI Reference Table

| BMI Range        | Classification     |
|------------------|--------------------|
| Below 18.5       | Underweight        |
| 18.5 – 25        | Normal weight      |
| 25 – 30          | Overweight         |
| 30 – 35          | Obesity class I    |
| 35 – 40          | Obesity class II   |
| Above 40         | Obesity class III  |

## SDG Alignment

This project is aligned with **Sustainable Development Goal 3 (Good Health and Well-being)**. It aims to promote awareness about healthy habits and provide accessible health information to the local community, while encouraging users to seek professional guidance when necessary.

## Disclaimer

This BMI calculator is a screening and educational tool. It is **not** a diagnostic instrument and should not be used as a substitute for professional medical advice, diagnosis, or treatment.

BMI does not directly measure body fat and may not be accurate for all individuals, including athletes, pregnant women, older adults, children, and people with certain medical conditions. For a complete health assessment, please consult a qualified healthcare professional.

The educational content provided in this application is based on public health recommendations from the World Health Organization (WHO), the Brazilian Ministry of Health, and the Virtual Health Library (BVS Saúde).

## Privacy

This application runs entirely on the client side. No user data is collected, stored, transmitted, or shared. All calculations are performed locally in the browser.
